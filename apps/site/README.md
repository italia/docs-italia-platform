# @docs-italia/site

Sito pubblico di Docs Italia (Astro, rendering lato server).

## Compiti

- Home, amministrazioni, publisher, progetti, documenti, ricerca, pagine istituzionali.
- URL identici al sito attuale; versioni archiviate; download.
- Italia Tailwind UI con il solo tema `italia-original`.

Piano di progetto: sezioni 6.4.
