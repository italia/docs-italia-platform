# @docs-italia/mcp

Server MCP dell'istanza per assistenti e agenti.

## Compiti

- Strumenti in sola lettura: `search_docs`, `get_section`, `get_toc`, `list_documents`, `list_versions`.
- Risorse MCP per ogni pagina pubblicata; trasporto Streamable HTTP; limiti di accesso.

Piano di progetto: sezioni 7.4.

## Dipende da

- `@docs-italia/retrieval`
