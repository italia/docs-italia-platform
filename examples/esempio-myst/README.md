# Documento di esempio

Documento MyST di prova per il toolkit: copre avvisi, figure, tabelle, link tra capitoli, etichette e riferimenti incrociati, note a piè di pagina, i ruoli e le direttive di Docs Italia, un sottocapitolo.

```sh
# dalla radice del repository
bun run docs-italia check --dir examples/esempio-myst
bun run docs-italia build --dir examples/esempio-myst
bun run docs-italia dev --dir examples/esempio-myst
bun run docs-italia studio --dir examples/esempio-myst
```
