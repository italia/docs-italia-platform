# @docs-italia/schema

Schemi di document_settings.yml, toc.json e del pacchetto di build, con JSON Schema generati.

## Compiti

- Validazione di `document_settings.yml` (retrocompatibile con il fork attuale) e `toc.json`, con messaggi in italiano.
- Tipi e schema del pacchetto di build: manifest, pagine, inventario, record di ricerca, frammenti.
- Generazione dei JSON Schema pubblicati in `spec/`.

Piano di progetto: sezioni 3.4, 3.5, 4.2.

Codice portato dal PoC (`_poc/packages/schema`) e poi esteso.
