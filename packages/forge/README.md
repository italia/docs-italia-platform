# @docs-italia/forge

Accesso ai fornitori Git: GitHub, poi GitLab.

## Compiti

- Lettura di `italia-conf` e dei repository dei documenti: branch predefinito, branch, tag, file.
- Webhook e GitHub App; verifica dei token OIDC delle GitHub Actions.
- Operazioni Git locali per lo studio (branch, commit, diff; mai push) e controllo che la cartella sia la radice del repository.

Piano di progetto: sezioni 2.2, 4.3, 5.4, 8.

Punto di partenza: `poc/packages/toolkit/src/git.ts` nel PoC.
